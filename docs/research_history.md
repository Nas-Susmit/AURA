# AURA research package — simulation proof of concept

## Reproduce
Python 3.11+ with NumPy, pandas, SciPy, scikit-learn and matplotlib. Run `python experiment.py` from this directory. Ten deterministic seeds (20261124–20261133). No network or patient data needed. Generated CSV metrics and figures are in `results/` and `figures/`. `synthetic_seed0.csv` is one clean generated population before observation perturbation; the other seeds are regenerated by the script. `pdflatex AURA.tex` twice compiles the paper with IEEEtran. 

## Evidence and dataset scope
The literature matrix is a targeted scoping matrix (44 distinct publications/resources), based on searchable publication metadata, abstracts and selected accessible full-text excerpts as of 2026-11-24. It is not a systematic review; no PRISMA flow, exhaustive coverage, double screening, formal bias scoring or full-text assessment of every entry is claimed. Source URLs are retained for human verification. Search clusters: axSpA/ankylosing spondylitis + AI/diagnosis/MRI; missing modality + clinical prediction; reliable multimodal fusion + uncertainty/conflict; selective classification + calibration; explainability; DESIR + data availability. IEEE author policy: https://conferences.ieeeauthorcenter.ieee.org/author-ethics/guidelines-and-policies/submission-policies/.

DESIR access requires a request and committee approval (https://pmc.ncbi.nlm.nih.gov/articles/PMC11337680/). SPACE and ASAS are candidates, but access and data dictionary have not been confirmed. The reviewed Xie and TabNet studies describe matched cohorts; no downloadable matched dataset with suitable permission was acquired. No clinical dataset was acquired or validated. No patient records were used. Do not use generated data to estimate clinical diagnostic accuracy. The simulator's numerical parameters are illustrative, not fitted to clinical prevalence or likelihood ratios.

## Data dictionary
`stiffness`, `movement_relief`, `night_pain`, `extra_articular`, `hla_b27`, `bme`, `erosion`: synthetic binary indicator. `crp_z`, `esr_z`, `structural_score`: dimensionless Gaussian proxies, not actual lab values or radiology scores. `synthetic_label`: generator's latent binary class (not physician diagnosis). `latent_mimic_audit_only`: latent mimic flag, never a model input. `split`: partition assignment. Quality scores are simulated observed proxies in [0,1]; masks and quality are generated on acquisition, not in the clean CSV. All-zero masks are excluded by forcing one uniformly random observed modality; no zero-input model result is claimed. In any future use, zero input must defer.

## Validation and limitations
Distinct train/gate/calibration/error-ranker/test partitions; shifted populations generated independently. Asserts check split uniqueness, zero weights for unavailable inputs, normalized weights, finite outputs, exact coalition attribution additivity and first-member logistic feature decomposition. The benchmark has 560 seed/scenario/model evaluations; scenarios share some held-out records, so inference uses seed-level paired differences, not individual cases. No prospective preregistration, clinician assessment, external cohort, clinical calibration, fairness audit, or actual MRI analysis. No tuning on reported test sets. The simple logistic baseline leads on macro AURC; the primary disagreement ablation has a confidence interval spanning zero. Report these faithfully. The threshold is fit on the same error-ranker development split and is descriptive only.
